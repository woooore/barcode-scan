# 🔍 얼마야 (편의점 · 대형마트 바코드 가격 & 1+1 스캐너)

편의점(GS25, CU, 세븐일레븐, 이마트24)이나 대형마트(이마트, 홈플러스, 롯데마트) 진열대에 가격표가 없을 때, **매장을 선택하고 바코드를 스캔하면 즉시 해당 매장의 판매가와 1+1 / 2+1 행사 여부, 체감 단가**를 알려주는 React Native (Expo) 크로스플랫폼 앱입니다.

---

## ✨ 주요 기능

1. **매장 선택 (편의점 4사 + 대형마트 3사)**
   - **편의점**: `GS25`, `CU`, `세븐일레븐`, `이마트24`
   - **대형마트**: `이마트`, `홈플러스`, `롯데마트`
   - 상단 매장 칩을 터치하면 현재 스캔한 상품의 가격과 1+1 행사 여부가 해당 매장 기준으로 즉시 전환됩니다.
2. **실시간 카메라 바코드 스캔 (`EAN-13`, `EAN-8`, `UPC` 등)**
   - 한국 표준 바코드(`880...`) 인식 및 어두운 진열대용 **손전등(조명)** 토글 지원
   - 카메라를 켜기 어려운 환경에서도 바로 테스트할 수 있도록 **원터치 인기상품 바코드 시뮬레이션 바** 및 **수동 바코드/상품명 검색** 지원
3. **1+1 · 2+1 체감 단가 & 타 매장 동시 비교**
   - 단품 가격뿐만 아니라 **1+1 행사 시 개당 체감가**를 크게 표시
   - 한 번 스캔으로 편의점 4사와 대형마트 3사의 가격 및 행사 여부를 한눈에 비교하고 **최저 체감가 매장** 자동 강조
4. **카운터 예상 결제금액 계산기 (장바구니)**
   - 상품을 여러 개 담으면 선택한 매장의 **1+1 / 2+1 무료 증정 수량을 자동 차감**하여 실제 카운터에서 결제할 총액을 계산
   - *예: 1+1 상품을 1개만 담았을 때 "1개 더 가져오셔도 결제 금액이 똑같아요!" 스마트 알림 제공*
5. **미등록 바코드 오픈 API 자동 조회 & 5초 현장 가격 제보**
   - DB에 없는 바코드 스캔 시 **Open Food Facts API** 및 로컬 행사 서버를 통해 상품명/브랜드를 자동 추출하고, 현장에서 바로 가격과 1+1 여부를 등록 가능

## 🚀 실행 방법

### 1. 패키지 설치 및 앱 실행
```powershell
cd "C:\Users\wooja\barcode scan"
npm.cmd install
npx.cmd expo start
```
- **스마트폰(아이폰/안드로이드)으로 테스트**: 스마트폰에 **Expo Go** 앱 설치 후 터미널에 나타나는 QR 코드 스캔
- **웹 브라우저에서 바로 화면 확인**: `npx.cmd expo start --web`

### 2. (선택) 바코드 가격/행사 백엔드 API 서버 실행
앱은 자체 내장 DB + AsyncStorage + Open Food Facts API로 단독 실행되지만, 크라우드소싱 가격 공유 서버를 함께 띄우려면 아래 명령어를 실행하세요:
```powershell
npm.cmd run server
```
